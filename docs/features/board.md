# 보드 (칸반)

상태 (2026-10-28): **구현됨** (D-234). `01-product.md` §4.3 의 보드를 티켓 목록 화면의 **보기 방식**으로 넣었다.

- 도구 줄 오른쪽의 보기 전환이 **목록 · 보드 · 타임라인 · 캘린더** 네 가지가 됐다. 주소 `?view=board`. 목록을 보드로 *바꾼* 것이 아니라 같은 화면의 한 보기라서, 내 티켓·요청한 티켓·전체 티켓 어디서나 쓰고, 검색·필터·"완료" 선택·"이번 사이클"·저장한 뷰가 목록과 똑같이 적용된다. 묶음·정렬은 보드에 없다(열이 상태).
- **열 = 상태**. 상태 목록의 순서(백로그 → 준비됨 → … → 완료 → 취소) 그대로. 열 머리에 상태 아이콘, 이름, 티켓 수.
- **카드**: 키, 제목(3줄까지), 우선순위, 라벨, 기한, 추정치(켠 프로젝트만), 담당자 아바타, 상위 티켓 키, 막힌 티켓이면 "막힘", 트리아지 대기면 "트리아지". 제목을 누르면 티켓 창이 열린다.
- **옮기기**: 카드를 다른 열로 끌어 놓으면 그 상태가 된다(HTML 끌어 놓기, 마우스). 키보드·터치는 카드의 상태 버튼(아이콘)으로 같은 일을 한다. 낙관적 갱신이라 놓는 즉시 옮겨지고, 실패하면 되돌아온다. 옮긴 것은 실행 취소(`Ctrl/⌘+Z`)로 되돌린다. 보기 역할·삭제된 티켓은 옮길 수 없다.
- "완료" 선택(2주 등)을 따라 끝난 지 오래된 티켓은 보드에서 빠지고 열 아래에 몇 개가 숨었는지 알린다.
- 좁은 화면: 열이 85% 폭으로 옆으로 밀려 넘어간다(보드는 가로로 넘기는 보기다).

코드: `features/issues/components/issue-board.tsx`, `issues-view.tsx`(보기 전환·옮기기), `issue-views.tsx`. 화면은 아무도 확인하지 않았다.
