# 티켓 구독 범위

2026-10-28 사용자 확정. 직접 구독은 해당 티켓만 / 하위 티켓 포함을 선택한다. 자동 구독과 기존 구독은 해당 티켓만이며 기존 직접 선택을 덮어쓰지 않는다.

하위 티켓 포함은 현재와 미래의 모든 자손 티켓에 적용한다. 하위에서는 상위에서 구독함으로 표시하고 누르면 그 티켓만 제외한다. 다른 자손과 상위 구독은 유지한다. 직접 다시 구독하면 제외를 해제한다. 여러 상위를 구독해도 해당 티켓 제외가 우선한다. 직접 구독과 상위 구독이 겹치면 직접 구독을 표시한다. 프로젝트 구독은 별도이며 이 제외로 끄지 않는다.

PUT /api/v1/issues/{number}/subscription 본문: {includeDescendants: boolean}, 생략하면 false. DELETE는 해당 티켓 제외. 활동 응답에 includeDescendants, inheritedSubscription 추가. subscribed는 직접 또는 상위로 구독하는지 나타낸다. 구독자 아바타도 유효 구독자를 표시한다. 기존 권한과 알림 통로 규칙을 따른다.

인수 기준: 범위 변경, 자동 구독 기본값과 선택 보존, 현재/미래 자손 알림, 상위 구독 표시, 한 자손만 제외 및 재구독.

화면: 활동 옆의 범위 선택을 바꾸면 즉시 구독/변경한다. 기본 구독 버튼은 해당 티켓만 구독한다. 범위·버튼은 낙관적으로 표시하고 오류가 나면 이전 서버 값으로 돌아간다. 명시적으로 제외한 티켓은 자동 구독으로 다시 켜지지 않는다.
