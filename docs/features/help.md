# 도움말

마일스톤 밖의 기능이다. 사용자 지정(2026-10-16, D-154).

## 무엇인가

Flowbit 의 사용 방법을 한 페이지에 모은 안내서다(`/help`). 지금 **구현되어 있는 기능만** 실제 화면의 이름 그대로 설명한다. 명세에만 있고 아직 없는 기능(트리아지, 사이클, 보드, 커맨드 팔레트의 액션, 한 글자 속성 단축키 등)은 쓰지 않는다.

## 들어가는 길

- 사이드바 왼쪽 아래(좁은 화면은 위쪽 줄 오른쪽)의 **사용자 메뉴**: "내 설정", "관리자 설정"(관리자만) 바로 아래에 **"도움말"**. 관리자 설정이 없는 구성원에게는 "내 설정" 바로 아래, 같은 묶음에 보인다.
- 주소 `/help` 를 직접 열어도 된다. 로그인한 누구나 볼 수 있다.

## 화면

- 맨 위 경로 표시는 "도움말" 하나.
- 넓은 화면(1024px 이상)은 **왼쪽에 목차**, 오른쪽에 본문. 목차는 본문을 스크롤해도 제자리에 있고, 지금 읽는 절이 강조된다. 좁은 화면은 본문 위에 목차가 있다.
- 목차와 본문은 두 묶음으로 나뉜다: **사용하기**(모든 사람)와 **관리하기**(관리자 설정의 각 탭). **관리하기 묶음은 관리자에게만 보인다**(구성원은 그 화면에 들어갈 수 없으므로). 구성원용 절에는 "관리자가 켜야 하는 것"(메일·푸시 알림, LDAP·SSO, Git 연동)을 한 줄씩 적는다.
- 절마다 주소의 `#` 이 있어 링크로 바로 열 수 있다(`/help#shortcuts`).
- "Git으로 일하기" 절은 키를 쓰는 곳별 연결 종류, 상태가 바뀌는 때, 지금 상태에 따른 결과를 표 세 개로 보여 준다(사용자 지정 2026-10-16). 내용은 `GitLinkService.kt` 의 실제 동작을 따른다.
- 단축키 절은 표다. `Ctrl` 은 macOS 에서 `⌘` 으로 보인다(`ModKey`).

## 내용의 위치

- 내용은 `frontend/src/features/help/content.ts` 의 데이터다(절 → 문단·목록·단계·표). 문구가 길어 `messages/ko.ts` 에 두지 않는다. 메뉴 이름과 페이지 제목 같은 짧은 문구만 `messages.help`, `messages.userMenu.help` 에 있다.
- 문장 안의 표시: `**굵게**`, `` `FB-12` ``(코드 모양), `[[Mod+K]]`(키 모양. `Mod` 는 Ctrl/⌘).
- **기능을 더하거나 바꾸면 이 파일도 함께 고친다.** 화면 이름("요청한 티켓", "목표 차트")은 `messages/ko.ts` 와 같아야 한다.
