# 요청함 제거 (2026-11-03 사용자 확정)

요청함 승인 단계를 제거한다. 프로젝트 접근·편집 권한은 유지하며 생성 즉시 일반 티켓으로 표시한다. 정리는 백로그·상태·담당자·취소·중복 연결로 처리한다.

- 화면·사이드바·단축키·설정·생성 체크·배지·분류 API·MCP 속성·분류 알림·거절 요청 보관 설정을 제거한다.
- V24로 기존 대기 티켓을 기본 백로그 상태로 옮긴다. 거절 티켓은 취소 상태를 유지한다. 본문·작성자·담당자·댓글·첨부·연결·삭제 여부를 보존한다. 이전 티켓 버전은 증가시킨다.
- 요청함 컬럼·인덱스와 거절 요청 보관 정책을 제거한다. 발송된 알림과 활동은 과거 기록으로 유지한다. 거절 티켓을 별도 보관 정책으로 삭제하지 않는다.
- 웹훅의 TRIAGE_REQUESTED 필터를 제거한다. 이 종류만 받던 웹훅은 비활성화해 전체 알림 구독으로 바뀌지 않게 하고, 다른 종류도 받던 웹훅은 나머지 필터를 유지한다.
- 기존 배포 마이그레이션은 수정하지 않는다. 운영 DB는 새 백엔드 배포 시 Flyway로 전환한다.
