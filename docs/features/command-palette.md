# 커맨드 팔레트, 단축키, 실행 취소

상태 (2026-10-28): **구현됨** (D-233). `01-product.md` §3 의 단축키 체계와 §4.6 커맨드 팔레트의 첫 판이다.

## 단축키는 한 곳(`lib/shortcuts.ts`)에서 정한다

모든 단축키의 키·이름·묶음이 `SHORTCUTS` 에 있다. **도움말의 단축키 표, `?` 시트, 명령 팔레트의 키 표시, 버튼 옆 키 모양**이 모두 이 목록을 읽는다(`KeyCaps`/`ShortcutKeys`, `shortcutRows`). 키를 듣는 코드도 이 목록과 맞아야 한다. 단축키를 더하거나 바꾸면 이 파일만 고친다(단위 테스트 `shortcuts.test.ts` 가 중복·빠짐을 본다).

| 키 | 하는 일 |
|---|---|
| `Ctrl/⌘+K` | 명령 팔레트(어디서나, 글을 쓰는 중에도) |
| `/` | 티켓·문서 검색 창 (전에는 `Ctrl/⌘+K` 였다) |
| `C` | 새 티켓 |
| `?` | 모든 단축키 시트 |
| `G` 다음 `M`·`R`·`I`·`T`·`P`·`S`·`H` | 내 티켓 · 요청한 티켓 · 전체 티켓 · 트리아지 · 전체 프로젝트 · 내 설정 · 도움말 (1.5초 안에 이어서) |
| `Ctrl/⌘+Z` | 방금 한 변경 실행 취소 |
| 그 밖 | `Esc`, `Ctrl/⌘+Enter`, `↑ ↓ Enter`, 편집기·둘러보기 키 |

한 글자 키와 `G` 이동은 글을 쓰는 중이나 창(`role=dialog`)이 열려 있을 때는 동작하지 않는다. `event.code`(물리적 키)로 듣기 때문에 한글 입력 상태에서도 같다.

## 명령 팔레트

`Ctrl/⌘+K` → 입력하면 이름과 키워드로 거른다(↑↓, Enter). 묶음: **할 일**(새 티켓, 검색, 실행 취소, 단축키 보기, 테마 밝게·어둡게·기기 설정), **보기**(목록 화면에서: 보드·목록·타임라인·캘린더로 보기 — 보기 전환과 같은 순서이고, 기본 보기인 보드는 주소에 `view` 를 남기지 않는다), **이동**(위 이동들, 관리자는 관리자 설정), **프로젝트**(들어갈 수 있는 프로젝트 이름). 명령마다 단축키가 있으면 오른쪽에 키 모양이 보인다.

## 실행 취소

티켓의 **상태·우선순위·담당자·기한·라벨·프로젝트·추정치**를 목록 줄, 보드, 캘린더 끌기, 티켓 창 속성에서 바꾸면 화면 아래에 "FB-12 상태 변경 · 실행 취소" 알림이 7초간 뜨고, 그 변경은 **이 탭의 실행 취소 기록**(최대 30개)에 쌓인다. 알림의 "실행 취소"나 `Ctrl/⌘+Z`(글 입력 중이 아닐 때)가 마지막 것부터 되돌린다. 되돌림은 바꾸기 전의 값을 다시 `PATCH` 하는 것이라, 그 사이에 다른 사람이 같은 값을 바꿨다면 덮어쓴다. 제목·본문·댓글·삭제·사이클·트리아지·관계 변경은 아직 기록되지 않는다(본문은 편집기 안의 실행 취소가 맡는다).
