# 09. 결정 기록

중요한 결정과 그 이유를 남긴다. 결정을 바꿀 때는 기존 항목을 지우지 않고 상태를 "대체됨(D-번호)"으로 바꾼 뒤 새 항목을 추가한다.

상태: **확정**(사용자가 결정) / **제안**(에이전트가 제안, 사용자가 반대하지 않으면 유지) / **대체됨**

## 미결정

결정되면 위 표로 옮긴다.

| 항목 | 내용 | 결정이 필요한 시점 |
|---|---|---|
| 기본 패키지 이름 | 현재 `com.flowbit` 으로 가정. 보유 도메인에 맞춰야 할 수 있다 | M0 시작 전 |
| UI 언어 | 기본 한국어 + 영어 지원으로 가정. 다국어 라이브러리(next-intl 등) 선택 포함 | M0 |
| 디자인 방향 | 색, 글꼴, 밀도, 브랜드 톤 | M0 (디자인 토큰 정할 때) |
| M1 세부 수치 | [features/M1-auth-and-setup.md](features/M1-auth-and-setup.md) 의 "확인이 필요한 것" (아이디 규칙, 비밀번호 길이, 잠금 기준, 세션 수명). 답이 없으면 제안값으로 구현 | M1 시작 전 |
| 운영 배포 방식 | Docker 이미지 + compose 한 파일로 배포할지, 다른 방식인지 | M1 완료 후 |
| M2 이후 범위와 순서 | [08-roadmap.md](08-roadmap.md) 의 초안 | 각 마일스톤 시작 전 |
| 라이선스 | 오픈소스 여부 | 공개 전 |
