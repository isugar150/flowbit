# 09. 결정 기록

중요한 결정과 그 이유를 남긴다. 결정을 바꿀 때는 기존 항목을 지우지 않고 상태를 "대체됨(D-번호)"으로 바꾼 뒤 새 항목을 추가한다.

## 미결정

결정되면 위 표로 옮긴다.

| 항목 | 내용 | 결정이 필요한 시점 |
|---|---|---|
| 기본 패키지 이름 | `com.flowbit` 으로 구현했다. 바꾸려면 지금이 가장 싸다 | 코드가 더 늘기 전 |
| 영어 지원 | 지금은 한국어만 있다 (D-026) | 영어가 필요해질 때 |
| M2 이후의 범위와 순서 | [08-roadmap.md](08-roadmap.md) 의 초안. Linear식 재설계에 맞춰 다시 짰다 | 각 마일스톤 시작 전 |
| 실시간 연결의 경로 | Next.js rewrite 로 WebSocket 을 전달할지, 리버스 프록시에서 직접 보낼지 | M3 시작 시 |
| M1 세부 수치 | [features/M1-auth-and-setup.md](features/M1-auth-and-setup.md) 의 "확인이 필요한 것" (아이디 규칙, 비밀번호 길이, 잠금 기준, 세션 수명). 답이 없으면 제안값으로 구현 | M1 시작 전 |
| 운영 배포 방식 | Docker 이미지 + compose 한 파일로 배포할지, 다른 방식인지 | M1 완료 후 |
| 라이선스 | 오픈소스 여부 | 공개 전 |
